# Kính

Dashboard / trình duyệt all-in-one, minh bạch và riêng tư. Xử lý dữ
liệu 100% trên máy người dùng, không server riêng, không chi phí ẩn.

Xem tiến độ và kế hoạch chi tiết trong [`PROGRESS.md`](./PROGRESS.md).

## Tải bản build sẵn

Vào tab **Releases** của repo này để tải `Kinh.apk` (Android) hoặc
`Kinh-Windows.zip` (Windows) — được build tự động mỗi khi có cập nhật.

## Chạy dự án (dev)

```bash
flutter pub get
flutter run
```
